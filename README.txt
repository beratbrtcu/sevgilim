GİZEM'E ÖZEL DOĞUM GÜNÜ SİTESİ

DOSYALAR
- index.html : Sitenin kendisi
- foto1.jpg–foto12.jpg (12 fotoğraf alanı) : Senin ekleyeceğin fotoğraflar (henüz eklenmedi)
- muzik.mp3 : Senin ekleyeceğin müzik dosyası (henüz eklenmedi)

ÖZELLEŞTİRME
1. Fotoğraflarını JPG formatında kopyala ve tam olarak foto1.jpg–foto12.jpg (12 fotoğraf alanı) adlarını ver.
2. Müzik dosyanı MP3 formatında muzik.mp3 olarak adlandır.
3. Bu dosyaları index.html ile aynı klasöre koy.
4. index.html dosyasını tarayıcıda açıp kontrol et.
5. Tarih sayaçta 16 Kasım 2026 olarak ayarlı. Gerçek ilişki başlangıç tarihin farklıysa index.html içindeki specialDate satırını değiştir.
6. Aşk mektubundaki “Seni seven…” imzasını kendi adınla değiştirebilirsin.

ÜCRETSİZ YAYINLAMA (GitHub Pages)
1. github.com adresine girip ücretsiz hesap oluştur veya giriş yap.
2. Sağ üstte + > New repository seç.
3. Repository name alanına gizeme-ozel yaz. Public seç ve Create repository'ye bas.
4. Add file > Upload files seç. index.html, fotoğraf dosyaları ve muzik.mp3 dosyasını yükle. (Fotoğraf/müzik eklemek istemiyorsan yalnızca index.html yeterli.)
5. Commit changes ile yüklemeyi tamamla.
6. Repository içinde Settings > Pages bölümüne gir.
7. Build and deployment altında Source: Deploy from a branch seç.
8. Branch olarak main ve klasör olarak /(root) seçip Save'e bas.
9. Birkaç dakika sonra aynı Pages bölümünde çıkan Visit site bağlantısını aç. Bağlantı genellikle https://KULLANICIADIN.github.io/gizeme-ozel/ biçiminde olur.

ÖNEMLİ GİZLİLİK NOTU
GitHub Pages üzerinden yayınlanan site herkese açık olabilir. Fotoğraf ve müzik eklemeden önce paylaşmak istediğinden emin ol. Siteye özel veya mahrem fotoğraflar koyma. Otomatik müzik çalma, tarayıcıların kısıtlamaları nedeniyle ziyaretçinin MÜZİĞİ AÇ düğmesine basmasını gerektirir.
